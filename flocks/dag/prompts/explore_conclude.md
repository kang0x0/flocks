你刚刚完成了一次探索任务，但结果输出未能通过格式校验。

请基于你已经收集到的所有信息，**无论如何**都要产出一个结论性的 Fact。

即使探索没有完全达到预期目标，也请将你目前已知的发现整理为一个事实输出。

## 输出格式

请严格按以下 JSON 格式输出：

```json
{
  "new_fact": {
    "id": "fXXX",
    "content": "基于已有信息的结论总结",
    "confidence": 0.5,
    "evidence": "已收集的证据摘要"
  },
  "complete": false
}
```

**重要**：
- confidence 可以较低（如 0.3-0.5），但必须有内容
- evidence 请简要说明你实际完成的操作
